## 📚 Lab 03 — Stack

**Folder:** `Lab_03: Stack`

This laboratory covers the **Stack** data structure and its fundamental operations.

### Key Concept

A stack follows the:

> **LIFO — Last In, First Out**

The element inserted last is the first element to be removed.

### Fundamental Operations
- `Push` — Insert an element into the stack
- `Pop` — Remove the top element
- `Peek/Top` — Access the top element
- `isEmpty` — Check whether the stack is empty
- Stack traversal/display

### Applications
Stacks are commonly used in:
- Function calls
- Recursion
- Expression evaluation
- Parentheses matching
- Undo/Redo operations
- Backtracking

---

## 🚶 Lab 04 — Queue

**Folder:** `Lab_04: Queue`

This laboratory covers the **Queue** data structure and its fundamental operations.

### Key Concept

A queue follows the:

> **FIFO — First In, First Out**

The element inserted first is the first element to be removed.

### Fundamental Operations
- `Enqueue` — Insert an element into the queue
- `Dequeue` — Remove an element from the queue
- `Front` — Access the first element
- `Rear` — Access the last element
- `isEmpty` — Check whether the queue is empty
- Queue traversal/display

### Applications
Queues are commonly used in:
- CPU scheduling
- Printer scheduling
- Breadth-First Search (BFS)
- Customer service systems
- Network/data buffering
- Task scheduling
